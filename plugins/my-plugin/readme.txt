A WordPress plugin scaffolded with WP Plugin Lab.

== Description ==

Short description shown in the WordPress.org plugin directory. The first sentence also appears in
search results, so it should explain on its own what the plugin does.

Features:

* Settings screen in the admin
* Custom post type with a taxonomy
* REST API endpoints under `my-plugin/v1`
* WP-CLI commands (`wp my-plugin info`, `wp my-plugin seed`)
* An "Item list" editor block

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/`.
2. Activate the plugin from the Plugins screen.
3. Configure it under Settings -> My Plugin.

== Frequently Asked Questions ==

= Does the plugin support multisite? =

Yes. Network activation initializes every site separately, and uninstalling cleans up the data on
each of them.
