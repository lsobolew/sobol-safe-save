# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[semantic versioning](https://semver.org/).

Keep the plugin-facing entries in sync with the `== Changelog ==` section of
`plugins/<slug>/readme.txt` - WordPress.org shows that one, not this file.

## [Unreleased]

### Added
- Initial starter: WordPress version matrix, test suites, dashboard, plugin boilerplate with a
  free and a paid edition, and the official WordPress agent skills.
- `wpx upgrade`, pulling newer lab tooling into a repository created from the starter.
- Block development on Vite and TypeScript, with three patterns: dynamic (PHP render), static with
  a deprecation, and an InnerBlocks container.
- Themes as a test dimension - the end-to-end suite sweeps block and classic themes.
- `wpx dev` (watch), `wpx theme`, and a `types` suite running `tsc --noEmit`.
- Skills describing this repository, installable at user level with `wpx skills global`.

### Changed
- The block build no longer uses `@wordpress/scripts`; `index.asset.php` is generated by the Vite
  build using the official WordPress externals mapping.
- Hook names use underscores (`myplugin_*`) to satisfy WordPress Coding Standards.
